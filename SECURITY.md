# Security Policy and Legal Disclaimer

## 1. Nature of the Software
This project is an open-source software application designed for media playback and communication over Peer-to-Peer (P2P) networks. The software acts strictly as a neutral technical client that processes network protocol transmissions and metadata solely at the explicit direction of the user.

## 2. Content Ownership and Hosting
* **No Content Hosting:** Neither this repository nor the software **hosts, stores, distributes, or commercializes** any media files, copyrighted material, or unlawful content on its servers or within its source code.
* **Third-Party Sources:** The application does not own or operate content delivery networks. Access to torrent files or media streams relies entirely on external, third-party sources or indexes provided or accessed directly by the user.
* **Non-Commercial Nature:** This software is provided free of charge, with no commercial intent, and does not monetize or profit from content delivery or third-party networks.

## 3. User Responsibility and Compliance
The use of this software is subject to applicable local and international laws and regulations. It is the sole responsibility of the end user to ensure that accessing, downloading, or streaming any media through this application complies with copyright laws and legal frameworks within their jurisdiction.

The developers and contributors of this project assume no liability for misuse, unauthorized content transmission, or any activities conducted by end users through the application.

## 4. Reporting Security Vulnerabilities
If you discover a security vulnerability within the source code (e.g., buffer overflows, memory safety issues, or remote code execution risks):

1. **Do not create a public issue.**
2. Send a detailed report with reproduction steps via [Your Contact Email or GitHub Security Advisories].
3. We will review and address reported technical vulnerabilities in a timely manner.
